# Config

This directory holds structured user configuration for the candidate.

- `profile.example.yml` is the setup template for profile settings.
- `profile.yml` is the active user-specific profile and should be treated as user data.
- `portals.example.yml` is the setup template for portal scanning.
- `config/portals.yml` is the active user-specific portal config and should be treated as user data.
- `templates/benchmarks.yml` contains broad illustrative analytics defaults.
  Copy it to ignored `config/benchmarks.yml` and replace the source, year,
  ranges, and caveats with candidate-relevant directional evidence.
