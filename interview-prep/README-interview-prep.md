# Interview Prep

This directory stores interview preparation artifacts generated over time.

- `story-bank.example.md` is the optional starter scaffold for the reusable STAR-style story bank.
- `story-bank.md` is your ignored local copy once you start accumulating real stories.
- Company- or role-specific prep notes can also live here.
- `sessions/` contains ignored private plan, practice, debrief, transcript, and
  structured snapshot artifacts.
- `offers/` contains ignored derived offer-review and negotiation-draft
  artifacts. Keep original sensitive documents under the root `offers/`
  directory.
